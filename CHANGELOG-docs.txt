# Обновление документации

Текст документации приведён в соответствие с текущей целевой сборкой AutoWallpaper:
- указана Windows 7 SP1 x64;
- инструкция скачивания готового ZIP перенесена в понятные шаги;
- убраны общие утверждения о поддержке других версий Windows;
- добавлено предупреждение о том, что совместимость требует проверки на реальной системе.
