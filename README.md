# AutoWallpaper — инструкция для Windows 7 x64

## Как скачать программу

1. Открой вкладку **Actions**.
2. Выбери последний запуск сборки со статусом Success.
3. Внизу страницы скачай архив `AutoWallpaper-Windows7-x64`.

## Как правильно установить

**Рекомендуемый способ — распаковать программу на диск C:.**

1. Открой папку «Загрузки».
2. Найди скачанный ZIP-архив `AutoWallpaper-Windows7-x64`.
3. Нажми по нему правой кнопкой мыши.
4. Выбери **«Извлечь все…»**.
5. В качестве папки назначения укажи `C:\AutoWallpaper`.
6. Нажми **«Извлечь»**.
7. Открой папку `C:\AutoWallpaper`.
8. Запусти `AutoWallpaper.exe`.

Если папки `C:\AutoWallpaper` ещё нет, её можно создать самостоятельно.

## ⚠️ Важно: как правильно запускать программу

Не запускайте `AutoWallpaper.exe` прямо из ZIP-архива или из временной папки.

Программа использует дополнительные DLL-файлы, которые должны находиться рядом с EXE. Если запустить только EXE или переместить его отдельно, программа может не найти необходимые модули и не запуститься.

### Рекомендуемый способ установки

1. Откройте папку «Загрузки».
2. Найдите архив `AutoWallpaper-Windows7-x64.zip`.
3. Нажмите по архиву правой кнопкой мыши и выберите **«Извлечь все…»**.
4. В качестве папки назначения укажите `C:\AutoWallpaper`.
5. Нажмите «Извлечь».
6. Откройте `C:\AutoWallpaper`.
7. Запустите `AutoWallpaper.exe` из этой папки.

**Важно:** хранить ZIP в «Загрузках» можно. Главное — полностью извлечь архив и не отделять EXE от остальных файлов и папок приложения.

Если программа не запускается даже после извлечения, сделайте скриншот ошибки.
