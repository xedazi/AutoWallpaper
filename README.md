# AutoWallpaper — автоматическая смена обоев Windows

## 📌 Что это за программа?

**AutoWallpaper** — приложение для автоматической смены обоев рабочего стола. Оно позволяет добавлять изображения в очередь, настраивать интервал смены обоев и включать повторное воспроизведение очереди.

## 💻 Для какой Windows предназначена программа?

- Windows 7 SP1 x64 (64-разрядная версия).
- Совместимость с конкретной системой зависит от установленных системных компонентов.

## 📥 Как скачать и установить программу

1. Откройте вкладку **Actions** в этом репозитории.
2. Выберите последний успешный запуск сборки со статусом **Success**.
3. В разделе **Artifacts** скачайте `AutoWallpaper-Windows7-x64`.
4. Откройте папку «Загрузки» и найдите скачанный ZIP-архив.
5. Нажмите на ZIP правой кнопкой мыши и выберите **«Извлечь все…»**.
6. Выберите постоянное место для программы, например `C:\AutoWallpaper`, и нажмите **«Извлечь»**.
7. Откройте созданную папку и найдите `AutoWallpaper.exe`.
8. Запустите EXE из этой папки.

## ⚠️ Почему нельзя просто достать EXE из ZIP?

Программа собрана вместе с дополнительными файлами и библиотеками DLL. Они нужны для её работы.

Если достать из архива только `AutoWallpaper.exe`, переместить его отдельно или запустить прямо внутри ZIP, необходимые файлы могут оказаться недоступны. В таком случае программа может не запуститься.

**Не удаляйте и не перемещайте отдельно файлы из папки приложения.**

## 🖥️ Как добавить программу на рабочий стол

Не нужно перемещать ZIP-архив на рабочий стол и запускать его оттуда.

1. Сначала полностью извлеките архив в постоянную папку, например `C:\AutoWallpaper`.
2. Откройте эту папку.
3. Нажмите правой кнопкой мыши на `AutoWallpaper.exe`.
4. Выберите **«Отправить» → «Рабочий стол (создать ярлык)»**. Если такого пункта нет, выберите **«Создать ярлык»**.
5. Теперь запускайте программу с рабочего стола через созданный ярлык.

Ярлык указывает на EXE в исходной папке. Поэтому не удаляйте эту папку и не перемещайте её после создания ярлыка.

## 🗂️ Где хранить изображения?

Изображения для обоев можно хранить в отдельной папке, например `C:\Wallpapers`, и добавлять в программу через её интерфейс.

## ❗ Если программа не запускается

- Убедитесь, что архив полностью извлечён.
- Проверьте, что `AutoWallpaper.exe` находится рядом с остальными файлами приложения.
- Не скачивайте DLL с неизвестных сайтов.
- Если появляется ошибка, сделайте скриншот и приложите его к сообщению.

**Важно:** зелёный статус сборки на GitHub означает, что сборка завершилась успешно, но сам по себе не гарантирует запуск на каждом компьютере с Windows 7.
