# AutoWallpaper

**AutoWallpaper** — небольшая программа для Windows, которая помогает управлять обоями рабочего стола и очередью изображений.

## Возможности

- Добавление изображений в очередь обоев.
- Изменение порядка изображений в очереди.
- Удаление изображений из очереди.
- Ручное применение выбранных обоев и переход к следующим.
- Автоматическая смена обоев по заданному интервалу, если эта функция включена в установленной версии программы.
- Сохранение пользовательских настроек.

## Совместимость

Текущая сборка проекта предназначена для **Windows 7 SP1, 64-разрядная версия (x64)**.

> Важно: совместимость зависит от конкретной сборки и установленных системных обновлений. Работа на Windows 8, 10, 11 и других конфигурациях этой сборкой не гарантируется.

## Как скачать готовую программу

1. Откройте репозиторий AutoWallpaper на GitHub.
2. Перейдите во вкладку **Actions**.
3. Откройте последний успешный запуск workflow **Build AutoWallpaper for Windows 7**.
4. Внизу страницы найдите раздел **Artifacts**.
5. Скачайте архив `AutoWallpaper-Windows7-x64`.
6. Распакуйте архив целиком в отдельную папку.
7. Запустите `AutoWallpaper.exe` из распакованной папки.

**Не перемещайте `AutoWallpaper.exe` отдельно от остальных файлов**, так как приложению могут требоваться библиотеки, находящиеся рядом с ним.

## Если программа не запускается

- Убедитесь, что используется Windows 7 SP1 x64.
- Установите доступные обновления Windows 7 и необходимые системные компоненты.
- Если появляется сообщение об отсутствующей DLL, сохраните скриншот ошибки и приложите его к сообщению в Issues репозитория.
- Если GitHub Actions завершился ошибкой, откройте запуск workflow и проверьте журнал шага, который завершился красным крестиком.

## Сборка

Проект собирается через GitHub Actions с помощью Python 3.8.10 и PyInstaller 5.13.2. Это выбранная конфигурация для попытки обеспечить совместимость с Windows 7 SP1 x64; фактическую совместимость следует проверять запуском на целевой системе.
