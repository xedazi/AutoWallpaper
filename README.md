# AutoWallpaper

Приложение для Windows, которое хранит очередь обоев и автоматически меняет их по таймеру.

## Возможности

- Добавление нескольких изображений в очередь.
- Перестановка изображений вверх/вниз и удаление.
- Ручное применение выбранных обоев и переход к следующим.
- Настраиваемый интервал автоматической смены: от 1 до 10080 минут (7 дней).
- Повтор очереди по кругу (включён по умолчанию).
- Автоматический запуск вместе с Windows и продолжение смены после входа в систему.
- Настройки и очередь сохраняются в `%APPDATA%\\AutoWallpaper\\settings.json`.

## Запуск из исходников

Требуется Windows и Python 3.10+.

```bat
python -m pip install -r requirements.txt
python app.py
```

Добавь изображения, задай интервал в минутах и нажми «Сохранить настройки». Флажки позволяют включать повтор очереди, автоматическую смену и автозапуск Windows.

## Сборка EXE

Запусти `build.bat` на Windows. EXE будет создан в папке `dist`.

Для автоматической сборки через GitHub Actions см. `.github/workflows/build-windows.yml`.

## Примечания

- Автозапуск создаётся для текущего пользователя Windows через ключ реестра `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run`.
- Программа не требует прав администратора.
- Закрытие окна останавливает таймер до следующего запуска. Для непрерывной работы оставь приложение открытым; включённый автозапуск запускает приложение после следующего входа в Windows.
