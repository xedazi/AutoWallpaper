AutoWallpaper — установка на Windows 7 x64
==========================================

1. Распакуйте ВЕСЬ архив в постоянную папку, например C:\AutoWallpaper.
   Не запускайте EXE прямо из ZIP-архива.

2. Не переносите AutoWallpaper.exe отдельно от остальных файлов.
   Не удаляйте DLL-файлы и папки рядом с EXE.

3. Нужна Windows 7 Service Pack 1 (SP1), 64-разрядная версия.

4. Если ошибка указывает на api-ms-win-core-path-l1-1-0.dll, это признак
   несовместимости компонента с Windows 7. Не скачивайте отдельные DLL
   с неизвестных сайтов — нужна сборка, специально совместимая с Windows 7.

5. Если ошибка указывает на Universal C Runtime / ucrtbase.dll, может
   потребоваться официальное обновление Microsoft KB2999226 для Windows 7 SP1 x64
   и перезагрузка.

6. Запустите AutoWallpaper.exe из распакованной папки.

Важно: PyInstaller упаковывает Python и Python-пакеты, но не может заменить
отсутствующие системные компоненты Windows. Успешная сборка на GitHub сама по
себе не доказывает, что программа запустится на каждой системе Windows 7.
